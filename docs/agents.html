Let an AI agent prepare your uploads. You stay in charge.

AutoUpload is built to be driven by AI agents. An agent can do the slow part (titles, descriptions, tags, checking every file) while you keep the final say and see each of its steps in the app.

How it works

AutoUpload includes an MCP server: autoupload mcp. MCP (Model Context Protocol) is the standard way AI agents use tools. The agent starts the server on your computer and talks to it directly; nothing goes through Ellipsio Studio, and the agent never sees your Google password, your token or your client_secret.json.

  • Free for agents: reading your channels and queues, adding videos to a queue, writing their details, previewing the dates, reading the calendar and the diagnostics.
  • Only if you allow it: uploading. It is off until you turn on Agents may upload.
  • Never: publishing a video as public at once, signing in to Google, or changing that permission.

Connect your agent

Install AutoUpload first (see the installation guide), then register the server once. In the app, AI agents → Connect an agent… shows these lines with the exact path of the program on your computer; autoupload agents setup prints them too.

Claude Code

claude mcp add autoupload -- autoupload mcp

Codex CLI, in ~/.codex/config.toml

[mcp_servers.autoupload]
command = "autoupload"
args = ["mcp"]

Cursor, Claude Desktop and other MCP clients: add a stdio server with command autoupload and argument mcp.

Practise first. Register autoupload --demo mcp instead to give the agent two sample channels and an offline YouTube. Nothing reaches your real channels, and the app started with --demo shows what the agent did.

What the agent can do

ToolWhat it does
statusYour channels, whether each one is signed in, how many videos wait, and whether agents may upload.
list_queueThe videos waiting in a channel's queue, each with its problem if it cannot be uploaded yet.
add_videoCopies (or moves) a video into a queue with its title, description, tags and other details.
write_sheetRewrites the details of a video already in the queue.
planThe publishing date each queued video would get. Uploads nothing.
uploadUploads the queue as private, scheduled videos. Refused unless you allowed it.
calendarWhat is already scheduled and published on the channel.
doctorSetup problems, each with its fix.
activityWhat you, the daily task and agents did recently.

What to ask it

Talk to the agent as you would to an assistant. For example:

  • “Queue every video in my exports folder for the channel mychannel. Write a specific title, a two-paragraph description and five tags from each file name and the notes in notes.txt. Then preview the dates.”
  • “Check the queue of mychannel and fix anything that would stop the upload.”
  • “What is scheduled for next week on both channels?”
  • “The new videos use an AI voice: mark them as synthetic media.”

A careful agent reads AutoUpload's guide for AI agents first: it asks you about facts it cannot see instead of inventing them, and shows you the dates before anything is uploaded.

Allowing uploads

By default the agent prepares and you press Upload in the app. To let it upload as well, turn on Agents may upload in the app's AI agents panel, or run in your own terminal:

autoupload agents allow-upload on      # off to take it back
autoupload agents status

Even then, uploads are private with a scheduled date, the same file is never uploaded twice, and the token must belong to the expected channel. An agent that tries to change this setting is refused.

See what it did

Everything done in AutoUpload, by you in the app, by you in a terminal, by the daily task or by an agent, is written to activity.jsonl in your data folder. The app's Activity tab shows it live, newest first, with a badge such as AI · claude-code on each action of an agent. In a terminal:

autoupload activity

Without MCP: terminal mode

Any agent that can run commands can use the command line instead. Every command takes --json for output a program can read, and setting AUTOUPLOAD_AGENT to the agent's name marks its actions in the activity log and applies the same permission:

AUTOUPLOAD_AGENT=my-agent autoupload queue mychannel --json
AUTOUPLOAD_AGENT=my-agent autoupload add mychannel clip.mp4 --title "Episode 5" --json
AUTOUPLOAD_AGENT=my-agent autoupload schedule mychannel --json

On Windows PowerShell, set it first with $env:AUTOUPLOAD_AGENT = "my-agent".
