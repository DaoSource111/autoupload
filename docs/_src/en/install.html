Download AutoUpload (ZIP) Repository on GitHub

§1Requirements

  • Windows 10 or Windows 11.
  • Python 3.10 or later, from python.org. During installation, tick Add python.exe to PATH.
  • A Google account that owns or manages the YouTube channel you want to upload to.
  • Access to Google Cloud Console with that account (free; no billing is needed for the YouTube Data API).

§2Download

Download the ZIP above and extract it to a folder of your choice, for example C:\AutoUpload. If you use Git, you can clone the repository instead:

git clone {REPO}.git C:\AutoUpload

The repository contains the source code only. It never contains credentials, tokens or anyone's channel data.

§3Install

Open PowerShell in that folder (in File Explorer, File → Open Windows PowerShell, or right-click → Open in Terminal) and run:

# create a private Python environment for AutoUpload
py -m venv .venv
# install AutoUpload and its dependencies into it
.\.venv\Scripts\pip install .
# check that the command works
.\.venv\Scripts\subidor.exe --help

The command-line tool is called subidor. Its commands are in English; the original Spanish command names still work as aliases.

§4Create a Google Cloud project and enable the API

AutoUpload connects to YouTube through an OAuth client that you own. The client file, client_secret.json, is never published or shared. Each installation creates its own:

  1. Sign in to Google Cloud Console with the Google account that owns or manages your channel, and create a project (for example, AutoUpload).
  2. Open APIs & Services → Library, search for YouTube Data API v3, open it and select Enable. Without this step every upload fails, with an error saying that the YouTube Data API has not been used in the project or is disabled.

§5Choose who can use the app

Open Google Auth Platform → Audience (the first time, Google asks you to configure the app with Get started). The user type and publishing status decide who can sign in and for how long the access lasts, as described in Google's Manage App Audience guide:

SettingWho can sign inWhat to expect
PersonalOnly the Google account that created the project.No verification, no “unverified app” screen and no 7-day expiry. It is a one-time choice when the project is created: it cannot be changed later or shared with other accounts.
External · TestingOnly the test users you add by their Google email address, up to 100.Google shows a warning before granting access, and every authorization expires seven days after consent: each user must sign in again once a week.
External · In productionAny Google account.Until Google verifies the app, users see an “unverified app” screen and the app is limited to 100 users in total. Authorizations no longer expire after seven days.

Recommended for one person: choose Personal if only you will upload, from the same account that owns the channel. For a small team: start in External · Testing, add each person as a test user, and select Publish app when the setup works, to stop the weekly sign-in.

§6Branding, permissions and test users

  1. Branding. In Google Auth Platform → Branding, enter the app name and a support email. Add a home page, privacy policy and terms of service if you will publish the app: Google requires them for external apps in production. Leave the logo empty unless you plan to request verification, because a logo requires it.
  2. Data access. In Data Access → Add or remove scopes, add only youtube.upload, youtube.force-ssl and youtube.readonly. Do not add other scopes: every extra sensitive scope widens what Google reviews.
  3. Test users (External · Testing only). In Audience → Test users, select Add users and enter the Google email address of every person who will connect a channel. If the channel is a Brand Account, add the personal Google account that manages it.

“Access blocked: … has not completed the Google verification process” (Error 403: access_denied). This appears when someone who is not a test user tries to sign in while the app is in Testing. Add that person's Google email address under Audience → Test users and try again.

§7Create the OAuth client

  1. In Google Auth Platform → Clients, select Create client and choose the application type Desktop app.
  2. Create it and download the JSON file.
  3. Save it in the AutoUpload folder as config\client_secret.json. Do not share it or upload it to any repository.

§8Create a folder for your channel

.\.venv\Scripts\subidor.exe channel new mychannel

This creates canales\mychannel\ with three items:

ItemPurpose
canal.yamlYour publishing hours, time zone, language, category and default tags.
queue\The queue: put the videos to upload here.
uploaded\Uploaded videos are moved here, each with a report.

§9Connect your channel

.\.venv\Scripts\subidor.exe auth mychannel login
  1. Your browser opens on Google's sign-in page. Choose your account and, if it manages several channels, the right channel.
  2. Google lists the three permissions AutoUpload requests. They are explained one by one on the home page. Select Allow.
  3. AutoUpload stores the access token in %APPDATA%\subidor-youtube and records your channel ID. From then on, it refuses to upload if the token belongs to a different channel.

What you may see. With an app in External · Testing, Google first shows that the app is in testing; with an app in production that Google has not verified, it shows “Google hasn’t verified this app”. In both cases, if the app is yours, choose Continue (or Advanced → Go to …). A Personal app shows neither screen.

Weekly sign-in in Testing. While the app is in Testing, the access expires seven days after you allowed it and uploads stop with an authentication error. Run auth mychannel login again, or publish the app (§5) so it no longer expires.

To check which channel is connected:

.\.venv\Scripts\subidor.exe auth mychannel whoami

§10Queue a video

Each video in queue\ needs a details file with the same name. A thumbnail with the same name is optional.

canales\mychannel\queue\
  episode-004.mp4     # the video
  episode-004.yaml    # its details (required)
  episode-004.jpg     # thumbnail (optional, .jpg or .png)

A minimal details file contains only the title. Every other field is optional:

title: The single point of failure
description: |
  What happens when one company holds the whole chain?
tags: [ai, hardware, markets]
publish_at: 2026-11-21T08:00:00-05:00   # fixed date; otherwise the next free slot
playlist_id: PLxxxxxxxxxxxx
captions:
  - {language: en, name: English, path: episode-004.en.srt}

§11Preview, then upload

# show the date each queued video will receive; uploads nothing
.\.venv\Scripts\subidor.exe schedule mychannel
# upload for real
.\.venv\Scripts\subidor.exe schedule mychannel --yes

Videos are uploaded as private and become public at their scheduled time. Check them in YouTube Studio after the first run.

§12Disconnect and remove

.\.venv\Scripts\subidor.exe auth mychannel logout

This revokes the token with Google and deletes it. You can also remove access at myaccount.google.com/permissions. To uninstall, delete the AutoUpload folder and %APPDATA%\subidor-youtube.
