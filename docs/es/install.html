Guía de instalación

AutoUpload funciona en tu propia computadora: lo instalas una vez y conectas tu canal desde ahí. Esta guía cubre cada paso, desde la descarga hasta tu primera subida programada. Calcula unos quince minutos.

Descargar AutoUpload (ZIP) Repositorio en GitHub

§1Requisitos

  • Windows 10 o Windows 11.
  • Python 3.10 o posterior, desde python.org. Durante la instalación, marca Add python.exe to PATH.
  • Una cuenta de Google que sea propietaria o administradora del canal de YouTube al que quieres subir.
  • Acceso a Google Cloud Console con esa cuenta (gratuito; la YouTube Data API no requiere facturación).

§2Descarga

Descarga el ZIP de arriba y descomprímelo en la carpeta que prefieras, por ejemplo C:\AutoUpload. Si usas Git, también puedes clonar el repositorio:

git clone https://github.com/DaoSource111/autoupload.git C:\AutoUpload

El repositorio contiene solo el código fuente. Nunca contiene credenciales, tokens ni datos de ningún canal.

§3Instalación

Abre PowerShell en esa carpeta (en el Explorador, clic derecho → Abrir en Terminal) y ejecuta:

# crea un entorno de Python propio para AutoUpload
py -m venv .venv
# instala AutoUpload y sus dependencias en él
.\.venv\Scripts\pip install .
# comprueba que el comando funciona
.\.venv\Scripts\subidor.exe --help

La herramienta de línea de comandos se llama subidor. Sus órdenes están en inglés; los nombres originales en español siguen funcionando como alias.

§4Crea tu cliente OAuth de Google

AutoUpload se conecta a YouTube mediante un cliente OAuth de tipo App de escritorio. El archivo del cliente, client_secret.json, nunca se publica ni se comparte. Cada instalación usa el suyo, que se crea en unos minutos:

  1. En Google Cloud Console, crea un proyecto (por ejemplo, AutoUpload).
  2. En APIs y servicios → Biblioteca, busca YouTube Data API v3 y pulsa Habilitar.
  3. En Google Auth Platform → Desarrollo de la marca, escribe el nombre de la app y tu correo de asistencia. En Público, elige Externo y añade tu propia cuenta de Google como usuario de prueba.
  4. En Google Auth Platform → Acceso a los datos, añade solo estos tres permisos: youtube.upload, youtube.force-ssl y youtube.readonly.
  5. En Clientes → Crear cliente, elige App de escritorio, créalo y descarga el archivo JSON.
  6. Guarda ese archivo en la carpeta de AutoUpload como config\client_secret.json. No lo compartas ni lo subas a ningún repositorio.

Mientras la app está en estado Prueba, Google hace caducar sus tokens a los siete días y tienes que volver a iniciar sesión. Para evitarlo, pulsa Publicar app en Público. Para uso propio no hace falta la verificación de Google: al iniciar sesión verás el aviso «app no verificada», donde eliges Configuración avanzada → Ir a la app.

§5Crea una carpeta para tu canal

.\.venv\Scripts\subidor.exe channel new micanal

Esto crea canales\micanal\ con tres elementos:

ElementoPara qué sirve
canal.yamlTus horas de publicación, zona horaria, idioma, categoría y etiquetas por defecto.
queue\La cola: aquí pones los videos por subir.
uploaded\Aquí se mueven los videos ya subidos, cada uno con su informe.

§6Conecta tu canal

.\.venv\Scripts\subidor.exe auth micanal login
  1. Se abre tu navegador en la página de inicio de sesión de Google. Elige tu cuenta y, si administra varios canales, el canal correcto.
  2. Google enumera los tres permisos que pide AutoUpload. Se explican uno a uno en la página de inicio. Pulsa Permitir.
  3. AutoUpload guarda el token de acceso en %APPDATA%\subidor-youtube y anota el ID de tu canal. Desde entonces se niega a subir si el token pertenece a otro canal.

Para comprobar qué canal está conectado:

.\.venv\Scripts\subidor.exe auth micanal whoami

§7Pon un video en la cola

Cada video de queue\ necesita una ficha con el mismo nombre. La miniatura con el mismo nombre es opcional.

canales\micanal\queue\
  episodio-004.mp4     # el video
  episodio-004.yaml    # su ficha (obligatoria)
  episodio-004.jpg     # miniatura (opcional, .jpg o .png)

La ficha mínima solo lleva el título. Todo lo demás es opcional:

titulo: The single point of failure
descripcion: |
  ¿Qué pasa cuando una sola empresa controla toda la cadena?
etiquetas: [ia, hardware, mercados]
fecha: 2026-11-21T08:00:00-05:00   # fecha fija; si no, el siguiente horario libre
lista: PLxxxxxxxxxxxx
subtitulos:
  - {language: es, name: Español, path: episodio-004.es.srt}

§8Revisa el plan y sube

# muestra la fecha que recibirá cada video de la cola; no sube nada
.\.venv\Scripts\subidor.exe schedule micanal
# sube de verdad
.\.venv\Scripts\subidor.exe schedule micanal --yes

Los videos se suben en privado y se hacen públicos a su hora programada. Revísalos en YouTube Studio después de la primera vez.

§9Desconectar y desinstalar

.\.venv\Scripts\subidor.exe auth micanal logout

Esto revoca el token ante Google y lo borra. También puedes quitar el acceso en myaccount.google.com/permissions. Para desinstalar, borra la carpeta de AutoUpload y %APPDATA%\subidor-youtube.

Si algo no funciona, consulta Soporte.
