Download AutoUpload (ZIP) Repository on GitHub

§1Requirements

  • Windows 10 or Windows 11.
  • Python 3.10 or later, from python.org. During installation, tick Add python.exe to PATH.
  • A Google account that owns or manages the YouTube channel you want to upload to.
  • Access to Google Cloud Console with that account (free; no billing is needed for the YouTube Data API).

§2Download

Download the ZIP above and extract it to a folder of your choice, for example C:\AutoUpload. If you use Git, you can clone the repository instead:

git clone {REPO}.git C:\AutoUpload

The repository contains the source code only. It never contains credentials, tokens or anyone's channel data.

§3Install

Open PowerShell in that folder (in File Explorer, File → Open Windows PowerShell, or right-click → Open in Terminal) and run:

# create a private Python environment for AutoUpload
py -m venv .venv
# install AutoUpload and its dependencies into it
.\.venv\Scripts\pip install .
# check that the command works
.\.venv\Scripts\subidor.exe --help

The command-line tool is called subidor. Its commands are in English; the original Spanish command names still work as aliases.

§4Create your Google OAuth client

AutoUpload connects to YouTube through an OAuth client of type Desktop app. The client file, client_secret.json, is never published or shared. Each installation uses its own, created in a few minutes:

  1. In Google Cloud Console, create a project (for example, AutoUpload).
  2. In APIs & Services → Library, search for YouTube Data API v3 and select Enable.
  3. In Google Auth Platform → Branding, fill in the app name and your support email. In Audience, choose External and add your own Google account as a test user.
  4. In Google Auth Platform → Data Access, add only these three scopes: youtube.upload, youtube.force-ssl and youtube.readonly.
  5. In Clients → Create client, choose Desktop app, create it and download the JSON file.
  6. Save that file in the AutoUpload folder as config\client_secret.json. Do not share it or upload it to any repository.

While the app is in Testing status, Google expires its tokens after seven days and you must sign in again. To avoid this, select Publish app in Audience. For your own use, Google's verification is not required: you will see an “unverified app” notice when you sign in, where you choose Advanced → Go to the app.

§5Create a folder for your channel

.\.venv\Scripts\subidor.exe channel new mychannel

This creates canales\mychannel\ with three items:

ItemPurpose
canal.yamlYour publishing hours, time zone, language, category and default tags.
queue\The queue: put the videos to upload here.
uploaded\Uploaded videos are moved here, each with a report.

§6Connect your channel

.\.venv\Scripts\subidor.exe auth mychannel login
  1. Your browser opens on Google's sign-in page. Choose your account and, if it manages several channels, the right channel.
  2. Google lists the three permissions AutoUpload requests. They are explained one by one on the home page. Select Allow.
  3. AutoUpload stores the access token in %APPDATA%\subidor-youtube and records your channel ID. From then on, it refuses to upload if the token belongs to a different channel.

To check which channel is connected:

.\.venv\Scripts\subidor.exe auth mychannel whoami

§7Queue a video

Each video in queue\ needs a details file with the same name. A thumbnail with the same name is optional.

canales\mychannel\queue\
  episode-004.mp4     # the video
  episode-004.yaml    # its details (required)
  episode-004.jpg     # thumbnail (optional, .jpg or .png)

A minimal details file contains only the title. Every other field is optional:

title: The single point of failure
description: |
  What happens when one company holds the whole chain?
tags: [ai, hardware, markets]
publish_at: 2026-11-21T08:00:00-05:00   # fixed date; otherwise the next free slot
playlist_id: PLxxxxxxxxxxxx
captions:
  - {language: en, name: English, path: episode-004.en.srt}

§8Preview, then upload

# show the date each queued video will receive; uploads nothing
.\.venv\Scripts\subidor.exe schedule mychannel
# upload for real
.\.venv\Scripts\subidor.exe schedule mychannel --yes

Videos are uploaded as private and become public at their scheduled time. Check them in YouTube Studio after the first run.

§9Disconnect and remove

.\.venv\Scripts\subidor.exe auth mychannel logout

This revokes the token with Google and deletes it. You can also remove access at myaccount.google.com/permissions. To uninstall, delete the AutoUpload folder and %APPDATA%\subidor-youtube.
